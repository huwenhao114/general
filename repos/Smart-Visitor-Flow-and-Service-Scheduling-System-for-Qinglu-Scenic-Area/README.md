## 一、项目简介

本项目针对青麓景区客流管理与服务调度中的**客流失衡、信息盲区、被动调度、决策模糊**四大痛点，提出基于 **IoT + AI + 云端协同** 的数智化转型方案，目标将平均停留时长提升 22%、调度响应时长缩短 75%、投诉率下降 44%。

## 四、MVP 启动步骤

### 方式一：Windows 一键启动（推荐）

1. 进入 `06-MVP/backend/` 目录
2. 双击 `start.bat`
3. 等待提示「后端服务启动中」
4. 浏览器访问 **http://127.0.0.1:5002/**

### 方式二：命令行启动

```bash
cd 06-MVP/backend
pip install -r requirements.txt
python app.py
```

启动后浏览器访问 **http://127.0.0.1:5002/**

> 首次启动会自动创建 `scenic.db` 数据库并填充 6 大区域 + 调度任务种子数据。

## 五、MVP 功能模块与演示流程

### 模块 1：客流看板（首页）
- 顶部 4 张统计卡：在园总客流、拥挤区域数、正常区域数、总区域数
- 6 大区域实时客流卡片（入口广场、核心观景区、西区竹林、南区花海、东区索道、北区古街）
- **点击任意区域卡片** → 弹窗修改客流 → 超承载量自动变红，并自动生成调度任务

### 模块 2：AI 分流
- AI 自动识别拥挤区域，生成分流建议（如"核心观景区→西区竹林"）
- 点击「刷新建议」重新计算

### 模块 3：协同调度
- 工单列表：显示所有调度任务（含优先级、部门、状态）
- 「+ 新建任务」手动创建工单
- 每个任务可「接单」「完成」操作
- **核心联动**：修改客流至超阈值时，系统自动生成一条分流任务

### 模块 4：调度记录
- 所有客流变更的历史记录表

### 推荐演示顺序
1. 首页查看 6 大区域当前客流与拥挤度
2. 点击「AI 分流」查看智能分流建议
3. 回到首页，点击一个拥挤区域，把客流改小（如改为 500）→ 观察拥挤状态变化
4. 再把一个正常区域客流改大至超承载量（如入口广场改为 2000）→ 观察自动变红
5. 点击「协同调度」→ 看到系统自动生成的分流任务 → 点击「接单」→「完成」
6. 点击「调度记录」查看客流变更历史

## 八、常见问题

**Q：双击 start.bat 报错找不到 Python？**
A：请先安装 Python 3.8+，安装时勾选「Add Python to PATH」。

**Q：浏览器访问 5002 端口无响应？**
A：确认后端窗口未关闭，且显示「Running on http://127.0.0.1:5002」。

**Q：想重置数据重新演示？**
A：删除 `06-MVP/backend/scenic.db`，重启后端即可重新生成种子数据。
